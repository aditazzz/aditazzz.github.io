def render_frame(t, W=1920, H=1080, fi=0):
    fmt = fmt_of(W, H)
    img, cam, hp = hdr(t, W, H)
    np.clip(soft_shoulder(img), 0, 1, out=img)
    out = cv2.pow(img, 1 / 2.2)
    out = apply_flip(out, flip_scale(t))
    out *= vignette(W, H)
    p = C.post(W, H)
    out += (cv2.resize(p.grain[fi % 6], (W, H), interpolation=cv2.INTER_NEAREST) * F32(0.012))[..., None]
    if not C.STATE["clean"]:
        out *= lyric_bed(W, H)
        if flip_scale(t) > 0.98: draw_labels(out, t, W, H, cam, hp, fmt); draw_stamps(out, t, W, H, cam, hp, fmt)
        draw_lyrics(out, t, W, H)
        C.subscribe_pill(out, t, W, H, 83.6, 5.0)
        C.end_screen(out, t, W, H, T_END, DUR - T_END, "Funny how it looks like us.",
                     sub_line="Subscribe for a new song every week", title="Mirror, Mirror, Look at Us", accent=ACC)
    out *= (1 - sstep(DUR - 1.0, DUR - 0.05, t))
    return (np.clip(out, 0, 1) * 255 + 0.5).astype(np.uint8)

What you see

A long dark hall lined with the bulb-lit vanity mirror from the cover art, each one bending the same face like a funhouse mirror. Every verse line turns to the mirror it's about and names what bends it, from AUTOCOMPLETE to AUTOPILOT. On every "mirror, mirror" the whole picture turns over like a hand mirror; on "look at us" every mirror in the hall straightens out and shows the same face. The lyrics are mirror-written and flip the right way round as each word is sung. The hall goes dark in the bridge, and on "mad" every mirror cracks at once, exactly where the cover is cracked.
