def render_frame(t, W, H, fi):
    t = float(t)
    sh = None
    for (a, b, fn, opts) in shots():
        if a <= t < b: sh = (fn, opts); break
    if sh is None:
        sh = (lambda t, W, H: wide(t, W, H, cam_master, 0.0), {})
    fn, opts = sh
    for (a, b, f_, o_) in shots():
        if f_ is fn and a <= t < b:
            CUR['u'] = (t - a) / max(1e-6, min(b, DUR) - a)
    img, S = fn(t, W, H)
    img = grade(img, S, t)
    if not opts.get('hide'):
        TY.lyrics(img, t, W, H, TM, lyric_place(W, H, opts.get('place')),
                  hide=lambda L_: L_['sec'] in ('INTRO', 'BREAK') or (L_['sec'] == 'POST1' and 'Slop' in L_['text'] and False))
    if t < 3.2:
        # opening title, quiet, over the empty 2 a.m. plaza
        op = sstep(0.25, 0.9, t) * (1 - sstep(2.5, 3.15, t))
        TY.title_card(img, W, H, ["AI Slop? You're Absolutely Right"], op, cy=0.14 if W > H else 0.16, size=0.052 if W > H else 0.05)
    C.subscribe_pill(img, t, W, H, L("I wrote the news, I wrote the review") + 0.4, 5.0)
    if t > T_END - 0.2:
        C.end_screen(img, t, W, H, T_END, DUR - T_END, "I'll be right behind you.", title="AI Slop? YOU're Absolutely Right")
    return C.finish(img, t, fi, DUR, ca=0.0012)

What you see

At 2 a.m. a woman on a plaza bench likes one post. She never looks up while the day time-lapses past. With every like her shadow outgrows physics: at dawn it climbs the Feed Tower, and every window it covers turns into a screen.

Her feed fills with a hundred identical sunsets, an LED band counts every scroll, the tower's windows spell SLOP, and the newsstand's yellowed tabloids (dated 1957 to 1994, all invented) show the same feeling decades before any AI. When her battery dies, so does the city's power, and the blackout finally shows the Milky Way. The final chorus reboots the city in neon.

Then she locks the phone, the towers go dark one by one, the sun comes up, and her shadow is just a shadow again. She opens her notebook and writes. The shadow waves.
